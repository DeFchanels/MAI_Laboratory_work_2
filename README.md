# Потоковый анализатор файлов
#### Python-пакет streamstats, читающий события из CSV и JSONL и создающий статистический отчёт.
## Скачивание и подготовка к использованию
1. Склонируйте или скачайте проект к себе
2. Создайте виртуальное окружение:
 - Введите в консоль команду `uv venv`. 
 - Затем пропишите `.venv/bin/activate`.
3. Установите pip в venv:
 -  `python -m ensurepip --upgrade`
4. Скачайте зависимости командой
 - `python -m pip install -r requirements.txt`
5. Используйте команду `uv pip install -e . `
#### После этого пакет доступен в консоли как CLI-утилита.

## Использование и тестирование
1. Для запуска пакета используйте команду:
 - `python -m streamstats analyze {INPUT file|files} --format {csv|jsonl} {--skip-invalid} --output {file_name.json}` <br/> <br/>
Вместо {INPUT file|files} введите пути к файлу/файлам, которые хотите проанализировать <br/> <br/>
--format - обязательный аргумент, вместо {csv|jsonl} введите либо csv если расширение введенных вами файлов .csv, и jsonl, если это .jsonl
<br/> <br/>
--skip-invalid - необязательный аргумент. Введите, если хотите пропускать неалидные события из файлов, записывая WARNING в лог и продолжая работу программы. Если аргумент не указан, на ошибочном событии программа будет завершаться с ошибкой
<br/> <br/>
--output - необязательный аргумент. Введите его и название файла после (вместо {file_name.json}) если хотите сохранить отчет по событиям в определенный файл. Если не указать аргумент, программа автоматически сохранит в output.json и output.csv
<br/> <br/>
Пример: `python -m streamstats analyze input_data/input.jsonl input_data/input1.jsonl --format jsonl --output result`
2. Для запуска тестов, находясь в основной директории проекта введите команду:
 - `python -m pytest `
